The Method

What is the Simplex Method?

The Simplex Method is an iterative algorithm for solving linear programming problems. Developed by George Dantzig in 1947, it navigates the vertices of the feasible polytope, improving the objective at each step until an optimal solution is found — or proves the problem is unbounded or infeasible.

📐
Standard Form
Every LP is converted to standard form: equality constraints with non-negative slack, surplus, and artificial variables, forming a structured initial basic feasible solution.
🔄
Pivot Operations
At each iteration, an entering variable (most negative reduced cost) and leaving variable (minimum ratio test) are selected. The pivot element drives row operations to update the basis.
🎯
Optimality Check
The algorithm terminates when all reduced costs in the objective row are non-negative (for maximisation), guaranteeing the current basic feasible solution is globally optimal.
♾️
Special Cases
The solver detects unbounded problems (no positive pivot column entries) and infeasibility (Phase-1 objective > 0), reporting them with clear diagnostic messages.
📑
Step-by-Step Iterations
The solver generates a Full Tableau History, allowing users to trace every pivot step. Each iteration displays the current basis, basic feasible solution, and the Z-value, making it an ideal tool for learning the manual Simplex process.
📉
Sensitivity Analysis
Post-optimality analysis determines the allowable ranges for objective function coefficients and right-hand side values. It identifies how much a parameter can change before the current basis is no longer optimal or feasible.
