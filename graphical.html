Two-Variable Method

Graphical Method Solver

Visualise the feasible region, corner points, and optimal solution on an interactive graph.

Problem Setup
The graphical method works for linear programs with exactly two decision variables (x₁ and x₂). It plots constraint boundaries as lines on a 2-D graph, identifies the feasible region, and evaluates the objective at each corner point.
Objective Function

Z =

x₁ + x₂

Non-negativity constraints x₁ ≥ 0, x₂ ≥ 0 are always assumed.
